# Security Policy

## Supported versions

The latest release on the `main` branch receives security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository
instead of opening a public issue. Include affected versions, reproduction
steps, impact, and any suggested mitigation. You can expect an acknowledgment
within seven days.

This library is not certified for safety-critical use. Security fixes are
handled as requirement-bearing changes and must pass the complete assurance
workflow before release.
